# Бумажный список задач

Тестовое задание: простой To-Do List. Статическая страница без фреймворков и без бэкенда —
задачи хранятся в `localStorage` браузера и переживают перезагрузку.

**Живая версия:** https://gohost1488-cmd.github.io/todo-paper/

## Что умеет

- добавление задач (Enter или кнопка), лимит 200 символов;
- отметка выполненной одним кликом (или `Space`);
- удаление: крестик, клавиша `Delete` или свайп по карточке на телефоне;
- сохранение после обновления страницы и после закрытия вкладки;
- фильтры «все / активные / готовые», счётчик активных, «убрать готовые»;
- правка текста двойным кликом;
- светлая и тёмная темы (запоминается), уважает системную настройку;
- управление с клавиатуры: `Tab` — фокус, `↑`/`↓` — по задачам, `Space` — отметить,
  `Delete` — удалить, `Enter` — сохранить правку, `Esc` — отменить;
- доступность: `aria-pressed`, живой регион для скринридеров, видимый фокус, `skip`-ссылка.

## Технологии

Никаких зависимостей во время работы: только HTML, CSS и JS. Шрифты системные,
иконка — inline SVG в `data:`-URI, внешних запросов нет вообще.

```
index.html            разметка + CSP
assets/styles.css     оформление (светлая/тёмная тема, адаптив)
assets/app.js         логика, состояние, localStorage
tests/e2e.mjs         11 сценариев на живом Chromium (playwright-core)
tests/shots.mjs       скриншоты для отчёта
.github/workflows/pages.yml  публикация на GitHub Pages
```

## Локальный запуск

```bash
python3 -m http.server 8099        # любой статический сервер
# открыть http://127.0.0.1:8099/
```

## Проверка

```bash
npm i -D playwright-core
node tests/e2e.mjs http://127.0.0.1:8099/
```

Проверяется: добавление, порядок, отметка, сохранение после перезагрузки, фильтры,
удаление и его сохранение, отсев пустой задачи, отсутствие исполнения HTML из ввода,
переключение и сохранение темы, отсутствие ошибок в консоли, отсутствие внешних запросов.

Текущий прогон: **15/15 проверок пройдено**.

## Какими ИИ-инструментами сделано

- **Hermes Agent** (агентная среда) — постановка, декомпозиция, проверка и деплой;
- **GPT-6 Luna (Codex)** — генерация кода страницы и правок;
- **Claude (devsec-ревью)** — отдельный проход по безопасности: XSS, CSP, работа с вводом,
  отсутствие секретов, поведение при битых данных в `localStorage`;
- **Playwright + Chromium** — сквозные проверки в реальном браузере и скриншоты.

## Безопасность

Кратко (подробно — в [SECURITY.md](SECURITY.md)): пользовательский текст вставляется
только через `textContent`, разметка никогда не собирается из строк; CSP ограничивает
источники своим доменом; в коде и репозитории нет ключей, токенов и внешних адресов;
деплой идёт через GitHub Actions с `GITHUB_TOKEN`, который живёт только внутри workflow.

## Ограничения

- данные привязаны к браузеру и устройству (это осознанный выбор: нет сервера — нечему утекать);
- нет синхронизации между устройствами;
- лимит 500 задач и 200 символов на задачу — защита от переполнения хранилища.
